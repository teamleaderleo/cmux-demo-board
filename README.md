# cmux demo board

A tiny three-column board for trying coding agents. No dependencies: plain HTML, CSS and ES modules,
with tests on Node's built-in test runner.

```sh
npm test      # runs in well under a second
npm start     # serves the board at http://localhost:4173
```

## The demo ask

> Add a keyboard-accessible filter to this tiny board and run its tests.

Reset between runs with `git reset --hard <pinned sha> && git clean -fd`.
